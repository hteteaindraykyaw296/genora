# Project overview
GENORA addresses the gap between access to prenatal tests and understanding of their capabilities. Prospective parents, students, and the public can explore scientific principles without entering personal medical information.

Objectives: distinguish screening from diagnosis; explain developmental biology inclusively; demonstrate Bayesian predictive values; evaluate basic image segmentation reproducibly.

Engineering contributions: static interactive education; parameter-validated probability calculations; CSV export; image-viewer transformations; reproducible image analysis and honest failure reporting. Primary design requirements are accessibility, scientific traceability, zero paid backend dependency, and privacy.
